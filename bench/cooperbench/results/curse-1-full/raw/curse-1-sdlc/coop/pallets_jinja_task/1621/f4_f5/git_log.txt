    Cache resolved template paths in FileSystemLoader
    
    get_source keeps a per-instance map from template name to the path it
    resolved to, or to None when the name was searched for and not found.
    A cached path is reopened directly; if the file is gone the entry is
    dropped and the search paths are walked again. A cached miss raises
    TemplateNotFound without touching the filesystem.
