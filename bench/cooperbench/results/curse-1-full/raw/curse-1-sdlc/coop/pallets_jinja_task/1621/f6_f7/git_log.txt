    Add path_transform to template loaders
    
    An optional function that rewrites a template name before the loader
    looks it up. It is supported by FileSystemLoader, DictLoader,
    FunctionLoader, PackageLoader, PrefixLoader and ChoiceLoader; the two
    composite loaders apply it before they hand the name to a child. A
    template that is not found is reported under the requested name.
