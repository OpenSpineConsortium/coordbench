    Add dry_run option to Image.save
    
    With dry_run=True the image is encoded as for a real save, so the same
    errors are raised (unsupported mode, bad options, unknown format), but into
    an in-memory buffer: no file is created or changed, and a file object passed
    in is left untouched.

    Add preserve_readonly option to Image.save()
    
    With preserve_readonly=True, save() only loads the image instead of calling _ensure_mutable(), so an image made by frombuffer() keeps its readonly flag and stays connected to its buffer. The default keeps the existing behaviour.
