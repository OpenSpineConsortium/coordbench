    Add process_priority to click.edit and Editor
    
    The editor can be started at a low, below normal, normal, above normal or
    high CPU priority. On Unix the niceness is set in the child between fork
    and exec, so the editor and what its shell starts inherit it; on Windows
    the matching priority class goes in the creation flags. An unknown value
    is ignored and a refused priority leaves the editor at its inherited one,
    so the edit never fails because of it. The default, None, changes nothing.
