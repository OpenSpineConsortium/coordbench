    Add search path monitoring to FileSystemLoader
    
    With auto_reload (on by default) the loader remembers the environments
    that load templates through it and polls its search paths from a daemon
    thread. A template whose file is modified, deleted or added is removed
    from those environments cache. The thread and the environment set hold
    only weak references, so neither keeps a loader or an environment alive.
