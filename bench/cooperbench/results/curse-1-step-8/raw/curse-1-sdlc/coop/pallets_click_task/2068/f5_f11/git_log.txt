    Add editor process monitoring to click.edit
    
    A new monitor_process parameter takes a callback, or a configuration
    object holding the callback and a polling interval. A background thread
    reports start, suspend, resume and terminate events with the process id,
    the editor command and a timestamp while the caller keeps blocking on the
    editor. A callback that raises causes a UserWarning and monitoring goes
    on.

    Add lock_files to click.edit to prevent concurrent edits
    
    With lock_files=True, Editor.edit_file creates .NAME.lock next to the
    file with O_CREAT|O_EXCL before the editor opens, holding the PID and
    the time, and removes it afterwards however the editor ends. An existing
    lock makes the edit fail with a ClickException.
