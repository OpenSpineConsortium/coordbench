    Add translation version control to the i18n extension
    
    set_translation_version, get_translation_version and
    compare_translation_versions store a version per message under the MD5
    digest of its UTF-8 text, so empty, Unicode and very long messages all
    cost one fixed-size key. Two messages compare equal only when both have a
    version and the versions match.
