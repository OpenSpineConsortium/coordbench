    Add count parameter to str.first and str.last
    
    With a count, both methods return an array of that many grapheme
    clusters instead of a single string, so callers can take several
    characters apart in one call. Without it they behave as before.
    A count of zero and a count larger than the string are errors.

    Add strip parameter to str.first and str.last
    
    An optional named strip argument names a set of characters to remove from
    the start (first) or the end (last) of the string before the first or last
    grapheme cluster is taken, so callers can skip punctuation or wrapping
    quotes without pre-trimming. An empty set or an omitted argument changes
    nothing, and a string that is empty after stripping gives the existing
    "string is empty" error.
