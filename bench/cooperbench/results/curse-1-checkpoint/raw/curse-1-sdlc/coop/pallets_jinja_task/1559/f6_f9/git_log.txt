    Add an LRU translation cache to the i18n extension
    
    The InternationalizationExtension keeps a bounded cache of translation
    results, sized by env.i18n_cache_size (default 128). _init_cache,
    _update_cache_size, _get_from_cache, _put_in_cache and clear_cache
    manage it; the least recently used entry is evicted first, and a size of
    0 turns it off. Each environment, overlays included, has its own cache.
