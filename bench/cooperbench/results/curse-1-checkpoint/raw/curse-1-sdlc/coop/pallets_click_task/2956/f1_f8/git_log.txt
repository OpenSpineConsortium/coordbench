    Add auto_complete to Option for context-aware completion
    
    An option with auto_complete=True completes its value from its type and
    name: a flag takes none, a plain string is matched by the words of its
    name (user, branch, file/path/dir, env) and anything else completes as
    its type does. A shell_complete function given to the option still wins.
    auto_complete is also reported in the info dict.

    Add track_changes to record option value history
    
    Commands and groups take track_changes=True; their context then keeps, for
    each parameter, the value, the source and a timestamp, read back with
    Context.get_option_history() by parameter name or option flag. It returns
    None when tracking is off, so the default costs one boolean per context.
