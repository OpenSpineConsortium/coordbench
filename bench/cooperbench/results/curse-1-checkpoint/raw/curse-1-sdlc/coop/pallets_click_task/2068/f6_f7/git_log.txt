    Add process_priority to click.edit and Editor
    
    The editor can be started at a lower or higher CPU priority: low,
    below_normal, normal, above_normal or high. Unix sets a nice value on
    the started process, Windows passes a priority class at creation. An
    unknown name is dropped and a refused or unsupported request is
    ignored, so the editor always runs. The default, None, changes nothing.
