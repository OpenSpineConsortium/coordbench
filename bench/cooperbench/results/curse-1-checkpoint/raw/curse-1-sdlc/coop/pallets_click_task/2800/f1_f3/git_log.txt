    Close contexts created during shell completion
    
    _resolve_context made contexts with make_context but never exited them,
    so click.File handles opened while parsing the complete args stayed open
    until garbage collection and raised ResourceWarning. File closes through
    the context's close callbacks, so enter each context with a with
    statement, for the main context, for the sub-context of a non-chained
    group and for the sub-contexts of a chained group.
